Everything you need to tame many calendars

One-click groups

Show only a group's calendars. Every other calendar is hidden instantly.

Fast mode

Uses Google Calendar's own "Display this only" option, so switching is quick even with 100+ calendars.

Build groups in seconds

Filter as you type, select all results, paste a list of names, or save the current view as a group.

Several groups at once

Combine groups — for example Football + Basketball — in a single view.

Automatic rules

Add every calendar whose name contains a word. New matching calendars join automatically.

Keyboard first

Ctrl+K palette inside Google Calendar, Alt+1…9 for your favourite groups, and Undo.

Multiple Google accounts

Groups and calendar lists are kept separate for each Google account.

Private by design

No servers, no tracking, no ads, no access to your Google account. Everything stays in your browser.
